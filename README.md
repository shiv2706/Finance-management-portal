# 💰 FinSmart — AI-Powered Finance Management Portal  
A full-stack MERN application for smart expense tracking, analytics, and automated financial insights.

FinSmart helps users **manage transactions**, **analyze spending**, and **get personalized insights** through an AI-powered RAG chatbot.  
It also supports **PDF/image bank statement extraction**, automated categorization, and interactive visual dashboards.

---

## 🚀 Key Features

### 🧾 Transaction Management
- Add, update, and delete transactions  
- Categorize income and expenses  
- Filter by date, category, or type  
- Clean, responsive UI

### 📊 Analytics Dashboard
- Pie & doughnut charts for category-wise expenses  
- Monthly spending & income breakdown  
- Interactive visualizations for quick insights

### 🤖 AI-Powered Chatbot (Gemini + RAG)
- Personalized answers based on **user’s own financial data**  
- Explains spending patterns, monthly totals, category-wise usage  
- Provides suggestions, insights, and actionable recommendations  
- RAG-based retrieval from stored financial data

### 🧠 Document Parsing & Auto-Categorization
- Upload **PDF or image bank statements**  
- Extract transactions using **regex patterns**  
- Automatically categorize entries using Gemini
- Input transactions using natural language queries aswell
- Reduces manual work & improves accuracy

### 🔐 Authentication & Security
- Secure login/signup  
- Password hashing  

### 📱 Modern UI
- React + CSS  
- Smooth navigation between dashboard, analytics, chatbot, and transactions
